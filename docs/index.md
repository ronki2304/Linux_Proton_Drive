## Key Invariants (at a glance)

- **SDK boundary:** Only `engine/src/sdk.ts` imports `@protontech/drive-sdk`
- **Widget isolation:** No widget file imports from another widget file
- **Single IPC connection:** Engine rejects second connections with `ALREADY_CONNECTED`
- **Protocol suffix:** `_result` suffix is reserved for correlated command responses
- **openpgp:** Full bundle only — never `openpgp/lightweight`
- **SDK version:** Pinned exactly at `0.14.3` — no `^` (pre-release API)
- **Credentials:** Never in plaintext on disk; libsecret primary, PBKDF2+Fernet fallback
- **Engine stdout/stderr:** Silent in production — all output via IPC push events or debug log
