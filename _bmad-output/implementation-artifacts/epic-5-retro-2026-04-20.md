7. **100% Epic 4 action item follow-through** — fifth consecutive epic.

## Challenges

1. **`queued_changes` count silently discarded in banner** — the engine computes and emits the queued-change count; `main.py` extracts it; `show_token_expired_warning()` accepts it but ignores it. The banner shows "Session expired" with no count. The re-auth modal (5-2) uses the count correctly. The first visible signal gives no urgency information. → Action item: wire count into banner text (6-0c).

2. **Deferred items accumulating faster than they close** — cleaned from 482 → ~150 lines in 5-0. Back to ~230 lines by end of Epic 5 (28 new entries from code reviews). Structural gaps repeat under new names: infinite retry, Sites 2–5 test coverage, stat() inner catch. → Root fix: schedule structural gaps as real stories (6-0a through 6-0e).

3. **Test spec routing assumption in 5-3** — story spec called for mocking `uploadFile` but actual routing uses `uploadFileRevision` for existing files. Dead mocks in initial implementation; review caught and cleaned. Means story dev context had an incorrect code-path assumption.

4. **Error detail UX gap** — users cannot read the actual error message. The full actionable text (`DISK_FULL: "Free up space on /dev/sda1"`, `PERMISSION_DENIED: "Check folder permissions for /home/user/Documents"`) is computed, emitted, and passed to `on_pair_error()` as `_message` — then discarded. The 'actionable' part of 'actionable errors' never reaches the user. → Action item: per-pair error detail UX (6-0d).
